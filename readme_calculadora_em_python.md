# 🧮 Calculadora em Python - AV2

Uma simples calculadora desenvolvida em Python com as operações básicas da matemática: **Adição**, **Subtração**, **Multiplicação** e **Divisão**.

## 📋 Descrição e Funcionamento

O programa funciona de maneira interativa diretamente no terminal:

1. **Escolha da operação:** O usuário seleciona qual operação matemática deseja realizar.
2. **Entrada de dados:** Em seguida, o programa solicita dois valores numéricos para serem calculados.
3. **Resultado:** O sistema processa o cálculo e devolve o resultado na tela.
4. **Continuidade ou encerramento:** Após visualizar o resultado, o usuário pode optar por realizar uma nova conta matemática ou selecionar a opção **SAIR** para encerrar o programa.

## ⚙️ Operações 

* ➕ **Adição**
* ➖ **Subtração**
* ✖️ **Multiplicação**
* ➗ **Divisão**
* 🚪 **Sair**
